# Notebooks

**자료 구조, 응답 추적, 결측 처리**를 다룬 탐색 Notebook 안내.

| Notebook | Content |
|---|---|
| [Data Structure](EXP002_data_structure_inspection.ipynb) | 차수별 변수와 원자료 구조 탐색 |
| [Response Tracking](EXP003_tracking_label.ipynb) | 응답 및 탈락 상태 탐색 |
| [Preprocessing](EXP004_preprocessing.ipynb) | CCA, LOCF, RevLOCF, MICE 결측 처리 |

- 핵심 Mundlak 모형은 [Scripts](../scripts/README.md)에 위치
- 제한자료와 로컬 경로 설정 필요. [Data 안내](../data/README.md) 참조
- **커밋 전 출력 셀 제거**, 개인 단위 미리보기와 ID 공개 금지
- 전체 실행 안내는 [Reproduction](../docs/reproduce.md) 참조
