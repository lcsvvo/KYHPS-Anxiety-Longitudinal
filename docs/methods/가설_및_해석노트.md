### 1-3. 이중 악화 집단 (스마트폰↑ & 수면↓)

  → 역치(threshold) 효과 가능성: 일정 수준 넘어야 우울 발생

## 2. 검증 가능한 가설 목록

### H1 (주가설): 스마트폰 사용 증가량 + 수면 감소량은 청소년 우울 발생과 정적 관계

- **형태**: 종단 연구 가설 (변화→변화)
- **측정 변수**: `smartphone_change`, `sleep_change` → `depression_w5` (2019 비우울자만)
- **예상 결과**: 스마트폰 변화량↑, 수면 변화량↓(더 감소) → 우울 발생 OR ↑
- **지지 근거**:
  - Onset 집단 스마트폰 변화량: +1.626 vs Stable +1.294 (p=.001)
  - 이중 악화 집단 우울 발생률: 15.6% vs 10.6% (Chi²=21.8, p<.001)
  - OLS: β_smartphone=+0.018, β_sleep=-0.014 (모두 ***)

### H2 (보완 가설): 스마트폰의 우울 효과는 여학생에서 더 강하게 나타남

- **형태**: 조절 가설 (성별 × 스마트폰 상호작용)
- **예상 결과**: 상호작용항 β > 0
- **확보된 근거**: 상호작용 β=+0.0112, p=.001 → **이미 지지됨**
- **경쟁 의의**: 성별 취약성 차이 → 맞춤형 개입 전략 제언 가능

### H3 (역설 가설): 학업스트레스 감소가 우울 발생의 보호 요인이 아닐 수 있음

- **형태**: 매개/역설 가설
- **근거**: Onset 집단의 학업스트레스 변화량이 Stable보다 더 크게 감소 (-0.862 vs -0.634)
- **해석**: 스트레스 감소 = 진정한 적응이 아닌 무기력화(academic disengagement)일 수 있음
- **추가 검증**: 학업성취(성적) 변수와 교차 확인 필요
- **⚠ 방향 주의**: 학업스트레스 변수의 코딩 방향(1=많음 vs 1=없음) 반드시 확인

### H4 (생활습관 복합 가설): 단일 요인보다 복합 생활습관 악화가 우울 위험 증폭

- **형태**: 복합 위험 가설 (additive/multiplicative)
- **제안 방법**: 스마트폰↑ + 수면↓ + 신체활동↓ + 패스트푸드↑ 중 해당 항목 수 → 점수화
- **예상 결과**: 복합 악화 점수↑ → 우울 발생률 단조 증가
- **현재 근거**: 2-factor 이중 악화만으로도 발생률 1.47배 (15.6/10.6)

### H5 (COVID 시기 가설): 코로나 시기(2020–2021) 스마트폰·수면 변화 폭이 이후 우울 궤적을 예측

- **형태**: 결정적 시기(critical period) 가설
- **측정 변수**: `smartphone_w2 - smartphone_w1` (2019→2020 변화량) → `depression_w5`
- **근거**: 스마트폰 최대 증가 시점 = 2019→2020 (COVID 직후)
- **분석 방법**: 조기 변화량 집단 vs 후기 변화량 집단 비교

## 3. 반직관적 발견 — 경쟁 전략적 활용

### 발견 A: "스트레스가 낮은 아이들이 더 우울해졌다"
- Onset 집단의 기저 학업스트레스: 2.868 vs Stable: 3.046 (낮은 스트레스에서 우울 발생)
- **스토리라인**: "스트레스 해소 = 행복이 아닌 시대 — 스마트폰이 채운 공백"
- **프레임**: 학업 부담 경감 정책의 역설적 효과 → 스마트폰/SNS 대체물이 우울 매개

### 발견 B: "수면이 가장 일관된 위험 신호"
- 수면시간: 5년 간 지속 감소 (가장 강한 선형 추세, Δ=-2.39)
- 이미 2019년에 Onset 집단의 수면 짧음 (선행 취약성)
- **스토리라인**: 수면 부족 = 독립 위험 요인이자 스마트폰의 매개 경로

### 발견 C: "절반 가까이(46.1%)가 이중 악화 — 우울 발생 위험 1.5배"
- 임팩트 있는 수치 → 정책 제언에서 직접 인용 가능
- "10명 중 5명이 스마트폰과 수면을 동시에 악화했고, 그중 6명은 우울해졌다"

## 5. 방법론적 한계 (논문 작성 시 명시)

1. **측정 불일치**: 2019년 스마트폰/수면 = 연속(시간), 2020–2023 = 순위형(1–9/1–8)  
   → 연속→순위 변환 적용; 해석 시 절대값 비교 불가, 순위 추세만 해석

2. **우울 이분 측정**: "우울감 경험(2주)" yes/no 단일 문항 → 임상 진단이 아닌 자기 보고  
   → 경미한 감정 상태도 포함; 과다 추정 가능성

3. **자기 보고 편향**: 모든 변수 학생 자기 보고 → 사회적 바람직성 편향 가능  
   → 특히 패스트푸드, 신체활동 과소/과대 보고 가능

4. **선택 편향**: 5년 완전 응답자(COMPLETE_5YR)만 분석 시 건강한 생존자 편향  
   → Missing 808명(16%)의 기저 특성 vs 응답자 비교 필요

5. **인과 추론 불가**: 패널 OLS는 시간 불변 혼란 변수 통제 불완전  
   → Fixed Effects 모형으로 보완 예정; 그래도 관측된 혼란 변수만 통제
